# タイムスタンプ（timestamps）生成ルール

タイムスタンプは手動入力が基本。以下の3モードを使い分ける。

---

## モード1：通常（時刻指定あり）

```yaml
timestamps:
  - time: 開始30分前後
    text: ...
    level: high
```

- `time`：10〜30分単位の目安（例：「開始15分前後」「開始1時間10分前後」）。秒単位は不要。
- `text`：ネタバレ防止のため「結果（誰が死ぬ・何が映るか）」は書かず、「予兆（音・場所・行動の変化）」のみ記載。
- `level`：`'high'`（要注意）／`'mid'`（注意）／`'low'`（低）のいずれか。

個別のびっくり演出を時刻で指定できる場合に使う。

---

## モード2：パターン（`type: 'pattern'`）

```yaml
timestamps:
  - type: pattern
    text: ドアの向こうに誰もいなくて安心したタイミングでびっくりがくる
```

全編にわたってジャンプスケアが多いが、ある程度パターンが決まっている作品に使う。  
`time` と `level` は不要。「こういうシーンで警戒」という形で記載する。複数エントリ可。

---

## モード3：なし（`type: 'none'`）

```yaml
timestamps:
  - type: none
```

ホラーコメディなど、ジャンプスケアがほとんどない作品に使う。  
`text` は不要（表示文言はテンプレート側で「✅ びっくり演出はほとんどない作品です」に固定）。  
`timestamps` にはこの1件だけを入れる（ほかと混ぜるとビルドが止まる）。  
**空配列 `timestamps: []` は「準備中」表示になるため、なしの場合は必ずこちらを使うこと。**

---

## その他

- 外部データベース（wheresthejump.com など）は Cloudflare のボット対策で自動 fetch できないことが多い。取得できない場合は人間に「該当ページの内容を貼り付けてほしい」と依頼する。
- 精神ダメージ・動物の安否に関する時間情報はデータベースにないため、目視確認または記憶ベースで作成する。
